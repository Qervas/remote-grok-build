# Optional bridge helpers (`~/.grok-bridge`)

| Script | Role |
|--------|------|
| `grok-mission-control.ps1` | LIVE / STALE / idle inventory |
| `grok-after-turn.ps1` | Reply pack: new images + optional git |
| `grok-interrupt.ps1` | Stop a headless grok turn by session_id |

Copy from `helpers/` into `~/.grok-bridge/` on the linked PC. Paths stay portable — never hardcode another user home.
